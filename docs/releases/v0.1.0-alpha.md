准备日期：2026-10-06，公开包确认更新：2026-10-07。此文档描述首个可公开展示的源码快照；本地准备完成不代表已经创建 GitHub 仓库、推送、发布 Release 或部署网站。

## 本版范围

SnapRec 的主线是“粘贴公开链接 → 确认来源与整理信息 → 写下自己的灵感 → 收藏 → 搜索与编辑”。元信息失败也可以保存普通书签。

本版包含统一 FastAPI 后端、SQLite 收藏与搜索、React Web App、公开元信息适配、来源封面安全缓存、用户作者与图片补充、显式编辑与重复项合并、2–10 项审核式批量导入，以及手机主动录音和转写草稿组件。系统分享接收已有浏览器实现，仍依赖安装状态、HTTPS 与浏览器支持，手动粘贴是默认入口。

网站已移除深度解析、字幕问答和结果阅读入口。历史后端模块与兼容接口保留，历史数据不会因这一网站变更被清理。MCP / Skill 入口未实现。

## 默认关闭与暂不提供

语音供应商默认未配置，仅用户主动录音可以进入个人灵感转写；不读来源音轨，不自动付费调用、不自动重试。启用供应商前需自行确认资源权限、费用、凭据和数据处理政策；本版不承诺供应商零留存或取消后不收费。

当前是单用户本机应用，没有登录、账户隔离或完整生产部署方案。公开源码包不附带个人手机网关、证书、防火墙规则或一键局域网启动链；不要直接开放到公网或不受保护的局域网。
